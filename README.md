# ربات پدر + ربات‌ساز فرزند

این نسخه شامل:
- پنل شیشه‌ای Inline برای ربات پدر
- ساخت ربات فرزند با هزینه ۵۰۰ تومان
- بررسی توکن و اجرای ربات فرزند
- ربات‌های من، حذف و وضعیت
- حساب کاربری
- خرید موجودی با ۹ مبلغ آماده و تأیید/رد ادمین
- زیرمجموعه با پاداش ۵۰ تومان و جلوگیری از پاداش تکراری
- پشتیبانی و پاسخ ادمین
- /panel برای ادمین
- آمار، موجودی، بلاک، ربات‌ها، خاموش/روشن پدر و فرزند
- انتخاب ۱۰ زبان در شروع ربات فرزند
- جستجوی موسیقی و دانلود صوتی با yt-dlp
- دانلود صوتی لینک اینستاگرام در صورت پشتیبانی yt-dlp

## نصب
Python 3.11 یا 3.12 پیشنهاد می‌شود:

pip install -r requirements.txt

فایل `.env.example` را به `.env` تغییر نام بده و BOT_TOKEN، ADMIN_ID و BOT_USERNAME را وارد کن.

سپس:

python main.py

نکته: Telegram InlineKeyboard رنگ آبی/سبز/قرمز واقعی برای دکمه‌ها ارائه نمی‌کند؛ چیدمان درخواستی اعمال شده است.

نکته پرداخت: چون در درخواست درگاه بانکی مشخص نشده، این نسخه پرداخت دستی و تأیید ادمین دارد.
